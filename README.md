# The Dragon Armoury Suite

A collection of open-source tools for financial data analysis, binary inspection, and regulatory compliance.

## Included Tools

| Tool | Description |
|------|-------------|
| Gullwing | Binary analysis and SBOM generation |
| Kestrel v2.0 | Inference acceleration for local LLM analysis |
| Albatross | DORA compliance workflow support |
| PartyVault | Cryptographic identity management demo |
| Corruption Tracker | Public procurement data analysis |
| ABRAXAS | Data visualisation interface |
