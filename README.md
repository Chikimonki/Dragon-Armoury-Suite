## The COBOL Problem

220 billion lines of COBOL run global banking. 60% of COBOL programmers retire in 5 years. $3T daily transactions depend on it.

**Gullwing-Swan** parses COBOL, extracts business logic, translates to Python. Estimated savings: $10-50M per institution, $50-100B globally.
