# The Dragon Armoury Suite

A collection of open-source tools for financial data analysis, binary inspection, and regulatory compliance.

## Tools

| Tool | Description | Repository |
|------|-------------|------------|
| Gullwing | Binary analysis and SBOM generation | [GullWing](https://github.com/forgottennord-ship-it/GullWing) |
| Kestrel v2.0 | Inference acceleration | [gullwing-kestrel-v2.0](https://github.com/Chikimonki/gullwing-kestrel-v2.0) |
| Gullwing-Auto | Vehicle ECU protection | [Gullwing---Auto](https://github.com/Chikimonki/Gullwing---Auto) |
| Albatross | DORA compliance workflow | [Albatross](https://github.com/Chikimonki/Albatross) |
| PartyVault | Cryptographic identity + ML trust | [partyvault](https://github.com/Chikimonki/partyvault) |
| Auditor-Smasher | Procurement audit + ML anomaly detection | [Auditor-Smasher](https://github.com/Chikimonki/Auditor-Smasher) |
| Corruption-Tracker-DS | ML anomaly detection for procurement | [Corruption-Tracker-DS](https://github.com/Chikimonki/Corruption-Tracker-DS) |
| Corruption-Tracker-V2 | React + browser ML | [Corruption-Tracker-V2](https://github.com/Chikimonki/Corruption-Tracker-V2) |
| ABRAXAS | Visualisation + Wellbeing | [ABRAXAS](https://github.com/Chikimonki/ABRAXAS) |
| Gullwing-Curlew | Supplier binary verification + Fleet | [Gullwing-Curlew](https://github.com/Chikimonki/Gullwing-Curlew) |
| HyperPolyglot | Cloud microservices demo | [hyperpolyglot-demos](https://github.com/Chikimonki/hyperpolyglot-demos) |
